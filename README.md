# Movesense GSP web viewer

The built site of the MovesenseGsp web app, version 0.2.0: open a MovesenseGsp recording (a folder or a zip of one)
and see every stream on one time axis with its gaps.

Use it at https://doingnz.github.io/movesense-web/ in Chrome or Edge. Recordings are read in the browser; nothing is uploaded.

This repository holds only the generated files. The source is in a private repository; do not edit these files by hand.
